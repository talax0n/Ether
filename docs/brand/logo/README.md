# Ether logo

Concept 1 pairs two overlapping swipe cards with a large grape spark for a mutual match. The chunky Ink outline and solid ledge carry the Arcade style, and the card stack and spark are both readable at 48 px. The adaptive icon uses Coral (#FF5A36).
