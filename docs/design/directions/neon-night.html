Neon Night

DIRECTION 2 / 3

A late-night hackathon rendered as a game HUD. Dark glass panels, neon edges and mono numerals. Every number looks like a stat you can raise.

Palette
Void #0A0A16 (bg) · Deep #12122A (surfaces) · glass = white 6% + 14% edge · Cyan #22D3EE (XP, info) · Magenta #FF3DAA (pass, badges) · Violet #8B5CF6 (ambient) · Lime #B6FF3B (like, energy, CTA) · Text #EDEBFF · Muted #A3A6C9.
Type
Space Grotesk 400/500/700 for words, JetBrains Mono 500–800 for every number, timer and label. Scale: 58 match / 30 name / 24 title / 15 body / 11 mono caps +2 tracking.
Shape
Radii 12 / 18 / 26. No outlines except 1dp hairline edges (white 14%). Elevation = glow, not shadow: colored outer blur 20–40dp at 50–70% alpha. Holo border = 1.5dp rotating sweep gradient. Hex = badges, ring = level.
Motion
Smooth and fast-out: tween(450, EaseOutExpo) ≈ cubic-bezier(.22,1,.36,1); springs only on drag release (dampingRatio .75). Light is motion: glows pulse 1.6 s, holo border rotates 6 s, match = flash → 3 pulse rings → 24 sparks → beam draws → log lines slide in 120 ms apart.
Iconography
Thin 1.8 stroke icons (Material Symbols Outlined, weight 300). Icons tinted with the accent of their meaning and given a 6–12dp glow when active.
Inspired by
Game HUD / esports stat screens, dark glassmorphism dating concepts on Dribbble, fitness ring progress (Apple Fitness / Strava-like rings), cyberpunk glitch titles. See ../references.md [Neon].
Compose build
Aura = layered Brush.radialGradient on drawBehind (no blur needed). Holo border = Brush.sweepGradient + rotate in drawWithContent. Glow = drawBehind with Paint.asFrameworkPaint().setShadowLayer or stacked translucent strokes. XP ring = Canvas.drawArc with animated sweep. Sparks / pulse rings = Canvas + withFrameNanos. Mono digits use FontFeatureSettings("tnum") so timers don't jitter.
Android risk
Medium. Backdrop blur: Compose has no native backdrop blur; Modifier.blur (RenderEffect) is API 31+ and blurs the node itself, not what's behind. Fallback: opaque-ish glass (#12122A at 85%) over pre-drawn radial gradients, which looks 90% the same. Glow via setShadowLayer is hardware-accelerated on API 28+; below that, use stacked alpha strokes. Keep animated glows off the scrolling list to save GPU on low-end phones.
A11y
Text #EDEBFF on Void 16:1, Muted #A3A6C9 on Void 8.2:1, Muted on glass ≥ 6.5:1. Lime CTA uses Void text (16:1). Never neon text for body copy, only for numbers ≥ 17sp. Targets ≥ 48dp. Reduced motion: glows static, no flash, no glitch, no sparks.
