# Bundled fonts

`app/src/main/res/font/` ships static instances of two Google Fonts, both under the SIL Open Font License 1.1 (https://openfontlicense.org):

- **Nunito** 600/700/800/900, © The Nunito Project Authors. Used for all words.
- **JetBrains Mono** 700/800, © The JetBrains Mono Project Authors. Used for every number, timer and XP value.

They are bundled so the app never fetches fonts over the network.
